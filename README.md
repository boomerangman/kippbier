# Kippbier

Ein Bierglas fürs Handy: Handy zum Mund kippen, das Bier läuft entsprechend aus.
Zapfen, Zischen, Blubbern und Gluckern werden live im Browser per Web Audio erzeugt – keine Audiodateien.

- `index.html` – komplette App in einer Datei, ohne Abhängigkeiten außer Google Fonts.
- Der Kippsensor braucht HTTPS (iOS fragt beim ersten Tippen auf „Zapfen“ nach Zugriff auf Bewegungsdaten).
- Ohne Sensor lässt sich das Glas mit dem Finger kippen.
- Die Haltung beim Tippen auf „Zapfen“ gilt als „aufrecht“; „Neu ausrichten“ setzt sie neu.
